# Pith v3.0.3

This is the first public v3 release, combining changes since v2.4.8. Review the breaking change before upgrading; `pith update` can offer newer major versions.

**Breaking: Thneed integration removed.** Pith no longer registers the specialized Thneed parser, exports the Go `ThneedParser` type, or runs Thneed to enrich diagnostics. An independently installed Thneed command can still be wrapped, but receives general processing rather than the removed Thneed summary format. Existing parser settings cannot restore it. No replacement retrieval engine is included. Explicit Gemini diagnostics still require `--allow-external-ai` and use Gemini when permitted; they are not offline.

**More faithful command results.** Normal child exit statuses now reach the CLI unchanged, including silent failures and success-looking failure output. Explicit `pith raw` returns all captured stdout followed by all captured stderr with no inserted separator, parsing, or truncation, including output above `MaxLines`. Middle-Out truncation now reports every omitted segment with its exact line count, including single-line gaps, while retaining selected lines once and in order. A final newline terminates the last line rather than becoming an extra tail line; actual blank lines and final newline are retained.

**Important boundaries.** Raw output combines child streams onto stdout; it does not preserve separate destinations or temporal interleaving. Pith's own error/usage diagnostics may still appear on stderr. Raw output can be much larger than before. Ordinary parser bypass and disabled parsers still use truncation. Generic wrapper errors and Unix signal termination retain exit 1; signal forwarding, `128 + signal`, and changed shell semantics are not provided. Omission counts describe Middle-Out's input, not recovery of content a parser already discarded. Parser completeness, full late-failure blocks, changed-file inventories and host-output recovery remain outside this release's promise. No performance or model-quality improvement is claimed.

**Packages and verification.** Native packages cover Linux amd64, Windows amd64 and macOS arm64. Each actual package receives focused smoke tests; this is not a full Windows/macOS suite or support for other architectures. The release includes SHA-256 binary checksums, a signature verified with the updater's embedded public key, and a CycloneDX SBOM. The signature covers the binary checksum manifest, not the SBOM. No Authenticode signing or Apple notarization is claimed.
