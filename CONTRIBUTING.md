# Contributing to Pith

Thanks for contributing. Please open an issue before substantial work, keep changes focused, and submit all code through a pull request to `main`.

## Development

- Build: `go build -o pith.exe main.go`
- Test: `go test ./...`
- Do not commit credentials, local telemetry, generated coverage, or machine-specific agent configuration.
